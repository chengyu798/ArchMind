# 会话上下文工程

## 策略与预算

后端通过 `app/config/context.yaml` 配置正式窗口 1,048,576 Token；输入达到 50% 时整理旧对话，目标是总输入占窗口的 20%～30%，通常选 25%。最近两轮较大时扩大保留范围。按完整轮次选择边界，保留近期原文；内容不足时不为了达到 20% 而填充。

窗口包含输入和输出，另预留输出 65,536、安全余量 8,192 Token。模型每次调用（包括工具循环）都会检查预算；一次用户请求最多尝试两次整理。单次问题或工具结果过大、无法安全压缩时保留记录并明确报错。

占用统计使用仓库内官方 DeepSeek V4 tokenizer，加上消息、系统提示、工具定义的序列化开销，属于本地估算，不等同服务商的实际计费。实际输入、输出和总消耗继续读取 API usage。当前配置适用于列出的 DeepSeek 模型；换其他模型需要配置对应容量、计数器与输出限制，不能假定其他模型也支持 1M。

模型规格来源：[DeepSeek 文档](https://api-docs.deepseek.com/quick_start/pricing/)、[官方配置](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash/blob/main/config.json)。tokenizer 来源、固定版本和许可证见 `app/assets/deepseek-v4-tokenizer/README.md`。

## 执行与持久化

普通后端函数负责预算、边界、校验和提交；独立的无工具模型调用负责生成摘要，不新增 Agent。聊天 Agent 仍负责回答和工具选择。摘要调用的回调上下文与回答隔离，避免重复累计 Token。

`SessionContextSummary` 保存版本、父版本、覆盖消息 ID、原文指纹、状态、模型、整理前后占用、摘要消耗和错误原因。内容分为 goals、constraints、facts、decisions、work_state，后者包含 completed、pending、open_questions。每条内容保存 ID、文本、状态、可信级别、来源消息 ID、替代关系及可选文件引用。

滚动整理输入上一版摘要、新增的旧消息和受预算限制的工具证据。验证 JSON、来源范围、引用权限、条目 ID、替代关系和最终大小；未被明确替代的有效目标、约束、决定会保留。摘要为有损模型生成，来源链接及原始记录用于核对，校验不能证明语义完全无损。

原始 `Message` 从不因整理删除。`ChatToolRecord` 另外存储工具参数、完整结果、状态和关联用户消息；不把工具返回误当作用户指令。每轮 `Message.usage_breakdown` 区分聊天调用和摘要调用，合计包含两者。

## 并发、失败与恢复

同一会话使用数据库原子租约串行处理，冲突返回 409；不同会话可以独立处理。摘要写入前比较会话版本、租约与原文指纹，过期执行者不能发布结果。租约默认 600 秒，后续阶段续租；进程中断后新执行者在租约到期时可接管，并将遗留生成中摘要标记失败。

摘要失败或超出目标预算时继续使用上一版摘要和原文；仍超过硬预算则停止本次模型调用并提示用户。源记录被修改时旧摘要失效，重新从原文构建。数据库升级只补列和新表，保留旧记录；删除会话时显式清理关联摘要和工具记录。

单次摘要请求也受硬预算保护。异常导入的超大历史若一次无法容纳，目前会报告失败，不会静默截断；尚未实现这种历史的多批次离线重建。

## 回查与界面

`search_conversation_history` 只接收关键词或消息 ID，用户和会话来自可信后端上下文。关键词回查返回受 Token 预算约束的结果；消息 ID 可查看邻近原文和工具证据。服务端所有接口校验当前用户拥有该会话。

接口为 `GET /api/chat/sessions/{id}/context`、`/context/summaries`、`/history`。SSE 增加 `context_status` 事件。页面提供折叠入口、占用、摘要版本、来源链接、关键词搜索和用量明细；生成期间禁止切换当前会话，避免串入另一个视图。

## 验证

运行 `.venv/bin/python -m pytest -q`、`npm --prefix frontend test`、`npm --prefix frontend run build`。新增检查涵盖触发边界、完整轮次、滚动版本、失败回退、来源/文件权限、租约竞争、过期执行、迁移、工具循环、用量隔离和浏览器组件交互。

真实模型在独立数据库和 24K 缩小窗口下连续生成两版摘要：第二版输入从 12,863 降至 6,135 Token（25.6%），保留数字 12345，正确标记被替代约束。正式窗口仍为 1,048,576；测试不更改正式用户的会话原文。正式页面另验证了历史工具调用、消息来源跳转和 Token 展示。
